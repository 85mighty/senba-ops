# 시공 체크리스트 — 인테리어 A안 (저공사·고급 갤러리 느낌)

> 3D 시뮬레이션은 참고용. 모든 치수는 **현장 실측 후** 발주. 임대인 승인 항목은 계약 전 서면 확인.

## 0. 보존 (철거·변경 금지 — 사용자 승인 전)
- [ ] 우드 패턴 바닥 그대로 (보양만)
- [ ] 회색 벽지 그대로 (손상부 부분 보수만)
- [ ] 검은 중간 가로 띠(체어레일) 색·위치 유지 — 스캔 측정 윗면 0.88 m·두께 0.08 m (줄자 확인 후 `--chair-rail`)
- [ ] 검은 걸레받이 유지 — 스캔 측정 0.10 m (줄자 확인 후 `--baseboard`)
- [ ] 창·문·주방·화장실·천장 레일·에어컨 위치 유지

## 1. 하부 화이트 사각 몰딩 (검은 띠 ↔ 걸레받이 사이)
- [ ] 벽마다 실측 길이 → 프레임 폭 균등 분할 (3D 기본: 폭 ≈0.9m, 간격 0.14m, 모서리 여백 0.18m)
- [ ] 콘센트·스위치·점검구·소화기 위치 피하기 (실측 후 `openings` 에 추가하면 자동 회피)
- [ ] 창 아래 벽, 문틀 옆은 프레임 폭 축소 또는 생략
- [ ] 자재: 우레탄/PVC 몰딩 45° 커팅, 화이트 (벽지 위 직접 부착 가능한 접착식이면 공사 최소)
- [ ] 옵션 `하단만 화이트 패널` 은 비용↑ → 기본 OFF, 견적 비교만

## 2. 중앙 넓은 기둥 4면 거울
- [ ] **거울 대상 기둥 1개 확정** — 현재 `wide_column_14` (0.26×0.82 m, 천장고 2.38 m). 변경 시 뷰어 ‘기둥 클릭’ → `--central-column <id>`
- [ ] 4면 실측: 폭·높이, 걸레받이 두께, 기둥 면이 바닥~천장까지 닿는지
- [ ] 거울 높이 (3D 기본 2.2m, 바닥 걸레받이 위부터) — 전신 비침 + 천장 설비 간섭 없는 높이
- [ ] 콘센트·스위치·점검구가 기둥 면에 있으면 → 해당 면은 거울 생략 또는 타공
- [ ] 안전: 비산방지 필름 필수, 모서리 보호 몰딩(검은색 → 걸레받이·띠와 통일), 하단은 걸레받이 위에 걸치지 않게
- [ ] 피난 동선·소방 사인 반사로 혼동 없는지 확인
- [ ] 부착: 미러 접착제 + 하부 받침 (석고보드 기둥이면 하중 확인)

## 3. 작품 디스플레이 (골드 액자)
- [ ] 레일 걸이(기존 흰색 행잉 레일 활용) vs 벽 피스 — 임대인 원상복구 조건 확인
- [ ] 액자 중심 높이 3D 기본: 띠 위 상부 벽 42% 지점 (약 1.8m 전후) → 실제 눈높이 1.5~1.6m 맞춰 조정
- [ ] 저작권: 퍼블릭 도메인 명화 or 자체 작품만. 참고 미술관 사진은 색감·분위기 참고용

## 4. 조명
- [ ] 기존 검은 트랙레일 재사용 → 헤드만 웜 화이트(2700~3000K, CRI 90+) 교체
- [ ] 작품·거울 반사 눈부심 각도 확인 (거울 정면 스팟 금지)
- [ ] 회로 용량·스위치 분리 (체험 수업용 밝은 모드 / 갤러리 모드)

## 5. 옵션 (기본 OFF)
- [ ] 와인/테라코타 포인트 벽: 개구부 없는 벽 1면 상부만. 전체 붉은색 금지
- [ ] 체험 테이블·스툴 배치: 기둥·주방·입구 동선 0.9m 이상 확보 (뷰어 가구 편집 → JSON 복사)

## 6. 3층·엘리베이터 없음 (고베 물건 공통)
- [ ] 거울·몰딩·테이블 반입 치수 vs 계단 폭·회전 반경 실측
- [ ] 소음·공사 시간대 제한 (쇼텐가이 건물 규정)
