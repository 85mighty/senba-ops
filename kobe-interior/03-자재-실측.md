# 03. 자재 사양 · 현장 실측

> 자재는 판매 페이지 표기값, 현장 값은 실측 전 3D 스캔 추정치(실측하면 ✅로 바꿔 적는다).
> 3D 뷰어 상수: `kobe-gallery-3d/src/editor.js` 의 `Editor.AIR_PANEL`

## 아래 벽 — 방법 ③ (판을 바닥~검은 띠 위끝까지, 위끝 見切り材)

### 벽 패널: エアサーモパネルlite Dタイプ (RESTA, ID 0000111669)

| 항목 | 값 |
|---|---|
| 크기 | 두께 7 mm × 폭 313 mm(앞면) × 길이 900 mm |
| 유효 폭 | **304 mm** (옆 판과 9 mm 겹쳐 끼움 — 장수 계산은 304 mm 기준) |
| 앞면 모양 | 나무결 시트 + 검은 세로 홈 (판 이음과 판 가운데) |
| 재질 · 무게 | 폴리스티렌, 약 853 g/장 |
| 가격 | 946엔/장 (1장 판매), 10장 세트 9,460엔 (2026-11-06 확인) |
| 샘플 | 유료 샘플 있음 — 색 확인용으로 먼저 주문 |
| 색 | (미정) — 샘플과 ダルグリーン 견본을 나란히 대 보고 결정 |

### 위끝 마감: エアサーモパネルlite 見切り材 (ID 0000111675)

| 항목 | 값 |
|---|---|
| 크기 | 깊이 25 mm × 높이 12 mm × 길이 1200 mm, 7 mm 홈(판 끝을 끼움) |
| 재질 | 폴리스티렌 |
| 가격 | 308엔/본 (2026-11-06 확인) |
| 용도 | 판 위끝(띠 위) · 창 아래 판 위끝 · 판 옆 단면(창 옆·벽 끝·기둥 모서리) |
| 주의 | 같은 가게의 見切り材 A·B·C, サイレント용은 두꺼운 판 전용 — **lite용만** 맞음 |

### 대략 수량 (스캔 기준 — 실측 후 다시 계산)

| 항목 | 계산 | 수량 |
|---|---|---|
| 판 | 벽 약 32 m + 기둥 둘레 약 7 m = 39 m ÷ 0.304 m | 약 129장 + 여유 → 140장 |
| 見切り材(위끝) | 39 m ÷ 1.2 m | 약 33본 |
| 見切り材(옆끝) | 기둥 모서리 20곳 × 0.9 m + 창·벽 끝 | 약 15~17본 |

## 현장에서 잴 것 (방법 ③)

| 항목 | 스캔 추정 | 실측 |
|---|---|---|
| 바닥 → 검은 띠 위끝 높이 (3~4곳) | 약 89 cm (900 mm 이하여야 판 1장으로 됨) | |
| 바닥 → 검은 띠 아래끝 높이 | 약 81 cm | |
| 검은 띠 높이 | 약 8 cm | |
| 검은 띠가 벽에서 튀어나온 두께 | 12 mm로 가정 (18 mm 이하면 見切り材가 틈을 덮음) | |
| 걸레받이 높이 | 약 10 cm | |
| 걸레받이가 벽에서 튀어나온 두께 (나무) | (미측정) — 띠와 비슷해야 판이 똑바로 섬 | |
| 벽별 길이 · 기둥 네 면 폭 | 3D 메타데이터 | |
| 창 아래 벽 높이 · 창 폭 | 창턱 약 55 cm | |
| 콘센트 · 스위치 위치(벽, 높이) | (미측정) — 판 따내기, 상자 앞으로 빼기는 電気工事士 | |
| 벽 평평함 · 모서리 직각 | (미측정) | |
