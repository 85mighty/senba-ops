# kobe-interior — 센바미술관 고베 산노미야점 인테리어

고베 2호점(산노미야 후보 물건) 인테리어 상담·설계·견적 기록용 폴더.
코드가 아니라 **의사결정 기록**이 원본이다. 상담은 `01-상담기록.md`에 날짜순으로 쌓는다.

## 파일 구성
| 경로 | 내용 |
|---|---|
| `00-현황.md` | 물건 조건·사업 전제·제약사항 (기존 손익 검토에서 가져온 확정 정보 + 미확인 항목) |
| `01-상담기록.md` | 인테리어 상담 로그 (질문 → 검토 → 결정). 새 상담은 맨 아래에 추가 |
| `02-요구사항.md` | 공간별 요구사항 정리 (상담이 진행되며 채움) |
| `kobe-gallery-3d/` | **Scaniverse LiDAR 스캔 → 정리·복원 → 인테리어 A안 3D 시뮬레이터** (작업 지시서 `CLAUDE.md`, 실행법 `README.md`) |
| `도면/` | 현장 실측·평면도·레이아웃 안 |
| `견적/` | 업체 견적서·자재 단가 비교 |
| `참고자료/` | 레퍼런스 이미지·본점 사진·자재 샘플 |

## 관련 자료 (이 저장소 내)
- `../sheets-scripts/senba-kobe.js` — 고베 산노미야점 후보 손익 검토 탭 (야칭공과금 20만, 손익분기 하루 5.0명)
- `../sheets-scripts/senba-shop2.js` — 2호점 시뮬레이션 탭 (큰 캔버스 + 석고 색칠 콘셉트)
- `../docs-2026-08-정리.md` — 본점 운영 개편 종합 정리 (가격·예약·수익 공식)

## 원칙
- 인테리어 예산은 손익분기(월 약 52~53만 → 고베는 더 낮음)를 흔들지 않는 선에서. 초기엔 "인테리어 최소" 전제.
- 사진·견적서 등 개인정보·업체 연락처가 포함된 원본은 커밋 전 확인.
