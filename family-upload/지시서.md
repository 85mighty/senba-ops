# 가족 영상 업로드 서버 구축 지시서

> 이 문서는 운영 서버(Vultr, senbaartstudio.com 호스팅 서버)에서 Claude Code에게 그대로
> 전달하는 작업 지시서다. 서버에서 `claude` 실행 후 이 파일을 읽고 작업하라고 하면 된다.
>
> 예: `이 지시서대로 가족 영상 업로드 서버를 구축해줘: family-upload/지시서.md`

## 목적

아버지(스마트폰 사용 미숙)가 **링크 하나만 눌러서** 영상을 올리고, 가족 누구나 같은 페이지에서
영상을 **다운로드**할 수 있는 초간단 업로드 페이지를 이 서버에 만든다.

- 로그인/계정 가입 없음. 링크에 비밀 토큰이 들어 있어서 링크를 아는 사람만 접근 가능.
- 화면은 한국어, 글씨 크게, 버튼은 사실상 하나("영상 올리기").
- 올라온 영상은 같은 페이지 아래에 목록으로 떠서 누르면 다운로드된다.

## 서버 기존 구성 (참고 — 건드리지 말 것)

| 서비스 | 위치 | 비고 |
|---|---|---|
| Square 웹훅 | `/opt/senba-square/` | pm2 `senba-sq-webhook` |
| 블로그 자동발행 | `/opt/senba-blog-auto/` | 크론 |
| biz-dashboard | `/opt/biz-dashboard/` | 포트 **3014** 사용 중 |
| nginx | `/etc/nginx/sites-available/` | 블로그 등 설정 존재 |

새 앱은 이 패턴을 그대로 따른다: `/opt/family-upload/` + pm2 + nginx 리버스 프록시.

## 요구 사항

### 1. 사전 확인 (작업 전 반드시)

1. `df -h /` 로 디스크 여유 확인. **여유가 15GB 미만이면 멈추고 사용자에게 보고**하고 지시를 기다릴 것.
2. 포트 **3015**가 비어 있는지 확인 (`ss -tlnp | grep 3015`). 사용 중이면 3016 등 빈 포트로 대체하고 이후 단계에 일관되게 반영.
3. `family.senbaartstudio.com` DNS가 이 서버 IP로 잡히는지 확인 (`dig +short family.senbaartstudio.com` 과 서버 공인 IP 비교).
   - **안 잡혀 있으면**: 사용자에게 "DNS 관리 페이지에서 A 레코드 `family` → 서버IP 추가" 를 요청하고,
     그동안 나머지 작업(앱·nginx 설정 작성)은 진행하되 certbot 발급은 DNS 반영 후에 할 것.

### 2. 업로드 앱 — `/opt/family-upload/`

Node.js + express + multer 로 작성. 파일 구성:

- `server.js` — 앱 본체
- `.env` — `PORT=3015`, `UPLOAD_TOKEN=<openssl rand -hex 16 으로 생성>` (**git에 절대 커밋 금지**)
- `package.json`
- 업로드 저장 경로: `/opt/family-upload/videos/` (없으면 생성)

앱 동작:

- `GET /?key=<토큰>` — 토큰이 맞을 때만 페이지 표시. 틀리거나 없으면 403과 짧은 안내문.
- 페이지 구성 (한국어, 모바일 우선, 글씨 크게 최소 18px, 버튼 크게):
  - 상단: "가족 영상 보관함" 제목
  - 큰 버튼 하나: **"영상 올리기"** → 파일 선택창 (`accept="video/*,image/*"`)
  - 선택 즉시 자동 업로드 시작 + **진행률 표시** (영상이 커서 오래 걸리므로 필수. "올리는 중 XX%… 화면을 끄지 마세요" 문구)
  - 완료 시 "올리기 완료!" 크게 표시
  - 하단: 올라온 파일 목록 (파일명, 올린 날짜, 용량) — 각 항목에 **"내려받기"** 버튼
- `POST /upload?key=<토큰>` — multer로 수신. 제한:
  - 허용 확장자: mp4, mov, avi, mkv, webm, 3gp, m4v + jpg, jpeg, png, heic, gif
  - 파일당 최대 **4GB**
  - 저장 파일명: `YYYYMMDD-HHmmss-원본파일명` (한글 파일명 깨지지 않게 처리)
  - **디스크 여유가 10GB 미만이면 업로드 거부**하고 "서버 저장공간이 부족합니다. 관리자(아들)에게 알려주세요" 메시지 반환
- `GET /download/<파일명>?key=<토큰>` — `Content-Disposition: attachment` 로 다운로드. 경로 탈출(`..`) 방지 필수.
- 외부 CDN·프레임워크 없이 인라인 HTML/CSS/JS 한 파일로. 꾸밈보다 단순함 우선.

### 3. nginx — `family.senbaartstudio.com`

`/etc/nginx/sites-available/family.senbaartstudio.com.conf` 생성 후 sites-enabled 링크:

- `proxy_pass http://127.0.0.1:3015;`
- `client_max_body_size 4096m;`
- `proxy_request_buffering off;` (대용량 업로드 시 디스크 이중 쓰기 방지)
- `proxy_read_timeout 1800s; proxy_send_timeout 1800s;` (느린 회선 업로드 대비)
- `nginx -t` 통과 확인 후 reload.
- DNS 확인됐으면 `certbot --nginx -d family.senbaartstudio.com` 으로 HTTPS 발급 (기존 certbot 자동갱신에 합류).

### 4. pm2 등록

```
cd /opt/family-upload && npm install
pm2 start server.js --name family-upload
pm2 save
```

### 5. 검증 (완료 보고 전 필수)

1. `curl -s -o /dev/null -w "%{http_code}" "https://family.senbaartstudio.com/"` → 403 (토큰 없음)
2. 토큰 포함 URL → 200, 페이지 HTML에 "영상 올리기" 포함 확인
3. 테스트 파일 업로드 → `videos/`에 저장 확인 → 다운로드 URL로 받아서 바이트 일치 확인 → 테스트 파일 삭제
4. `pm2 status` 에서 family-upload online 확인

### 6. 저장소 반영

- `server.js`, `package.json`, nginx conf를 senba-ops 저장소 `family-upload/` 에 복사 (기존 `sync.sh` 패턴 참고, 필요하면 sync.sh에 경로 추가).
- `.env`와 `videos/` 내용물은 **커밋 금지**. `family-upload/.gitignore`에 명시.
- README.md 구성 표에 한 줄 추가: `family-upload/` | 가족 영상 업로드 (:3015, pm2 family-upload) | `/opt/family-upload/`

### 7. 완료 보고

작업이 끝나면 사용자에게 다음을 보고:

1. 아버지/가족에게 보낼 **완성된 링크** (`https://family.senbaartstudio.com/?key=토큰`)
2. 카톡에 그대로 붙여넣을 안내문:
   > 아빠~ 영상은 이제 여기에 올리면 돼요.
   > 아래 링크 누르고 → "영상 올리기" 버튼 → 영상 선택하면 끝!
   > 올린 영상은 같은 화면 아래에서 가족 누구나 받을 수 있어요.
   > (링크)
3. 현재 디스크 여유 용량과, 영상이 쌓였을 때 정리하는 방법 한 줄 (`/opt/family-upload/videos/` 에서 오래된 파일 삭제)

## 주의

- 기존 서비스(Square 웹훅, 블로그, 대시보드) 설정·프로세스는 절대 건드리지 않는다.
- 토큰이 곧 비밀번호다. 로그에 토큰 전체를 남기지 말 것.
- 이 지시서 범위를 넘는 작업(방화벽 변경, 기존 nginx conf 수정 등)이 필요해 보이면 먼저 사용자에게 물어볼 것.
